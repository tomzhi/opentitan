# 远程开发连接保护、后台任务保活与会话恢复最佳实践指南

## 1. SSH 网络突发断开时的底层机制分析

在远程 VPS / 服务器上执行诸如芯片编译（Verilator）、AI 模型训练或大型长耗时任务时，经常面临 SSH 连接中断（网络抖动、客户端休眠、超时等）风险。其底层行为表现如下：

### 1.1 进程与信号（SIGHUP）传递
* **前台 CLI 交互进程 (`agy`)**：
  若直接在普通的 SSH 会话（如 `/dev/pts/0`）中前台启动 `agy`，当 SSH 连接断开时，系统内核会向该终端会话控制进程发送 `SIGHUP`（挂断信号），导致未做守护保护的前台 CLI 进程异常退出。
* **底层构建子进程（Bazel / Verilator）**：
  在 OpenTitan 构建中，Bazel Server 会自动转为独立系统守护进程（其父进程 PID 挂载为 `1`，即 `systemd/init`），运行在沙箱隔离进程组中。因此即使 SSH 突发断连，底层的编译子进程通常仍会在 Linux 后台继续计算，不会随 SSH 立即夭折。

## 2. Antigravity 历史对话恢复方法

Antigravity 具备完备的会话持久化（Conversation Persistence）机制，即使 CLI 界面因断网被动中断，对话数据绝不会丢失。

### 2.1 会话存储位置
* **会话唯一标识符 (Conversation ID)**：当前对话具有全局唯一 ID（例如 `5f0673a4-f875-486b-9b91-af0c133caf92`）。
* **持久化文件存储路径**：
  ```bash
  /root/.gemini/antigravity-cli/brain/<conversation-id>/
  ```
  对话日志、工具调用历史、执行状态等全部实时落地于此目录。

### 2.2 恢复连接与继续对话
重新通过 SSH 登录服务器后，可通过以下方式无缝恢复历史对话：
1. **交互式列表恢复**：
   直接执行 `agy`，在启动欢迎主界面中选择 **Resume recent conversation**，选择上一次对应的对话即可。
2. **精准指定 ID 恢复**：
   如果已知具体会话 ID，可直接执行：
   ```bash
   agy resume <conversation-id>
   ```
   *当前 OpenTitan 项目会话恢复命令*：
   ```bash
   agy resume 5f0673a4-f875-486b-9b91-af0c133caf92
   ```

## 3. 强烈推荐的最佳工程实践：使用 `tmux`

为彻底解决网络掉线、终端关闭对长耗时任务和 AI 交互的影响，在 VPS 上进行协作时的**黄金准则**是：**始终在 `tmux` 虚拟终端会话中运行 `agy`**。

### 3.1 核心优势
1. **彻底免疫 SIGHUP**：`tmux` 服务常驻在后台，SSH 掉线只会断开前端显示，会话内部运行的 `agy` 和所有任务 100% 持续平稳运行。
2. **无缝秒级接回**：重连 VPS 后只需一条命令，立刻恢复掉线前的完整字符界面（含历史输出、光标位置）。
3. **多窗格并发监控**：支持同屏切分窗口，一边与 Antigravity 对话，另一边实时监视 `htop` 或编译日志。

---

## 4. `tmux` 常用标准操作指引

### 4.1 标准推荐流程
```bash
# 步骤 1：SSH 登录 VPS 后，创建/进入一个专用的 tmux 会话（例如命名为 ot）
tmux new -s ot

# 步骤 2：在 tmux 会话内正常启动 Antigravity 进行长耗时交互
agy

# （如果突发网络中断或主动关闭电脑后）

# 步骤 3：再次 SSH 登录 VPS，直接接回会话，界面原样呈现
tmux attach -t ot
```

### 4.2 常用快捷键速查（按键前缀默认为 Ctrl + b）
* **脱离会话（保持后台运行）**：按下 `Ctrl + b` 然后按 `d` (Detach)。
* **垂直分屏（左右并排）**：按下 `Ctrl + b` 然后按 `%`。
* **水平分屏（上下并排）**：按下 `Ctrl + b` 然后按 `"`。
* **在不同分屏窗格间切换**：按下 `Ctrl + b` 然后按 `方向键`。
* **查看现有所有 tmux 会话列表**：
  ```bash
  tmux ls
  ```
* **退出并彻底销毁会话**：在会话内输入 `exit` 或执行 `tmux kill-session -t ot`。
